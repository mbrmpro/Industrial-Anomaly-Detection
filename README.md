# Industrial Anomaly Detection

## Overview

This application presents the complete workflow of an industrial anomaly detection project based on the MVTec AD dataset.

The application demonstrates:

- Business Understanding
- Dataset Exploration
- Data Preprocessing
- Feature Engineering
- Baseline Models
- PatchCore
- Model Evaluation
- Interactive Visualization

---

## Dataset

MVTec AD Dataset
